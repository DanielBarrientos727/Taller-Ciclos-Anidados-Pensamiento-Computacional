# Taller de Ciclos Anidados – Pensamiento Computacional

Repositorio académico con el desarrollo del taller de **Ciclos Anidados**, correspondiente a la asignatura de **Pensamiento Computacional**.

El proyecto reúne los ejercicios realizados inicialmente por **Daniel Barrientos y Andrés Santa**, junto con nuevos ejercicios desarrollados por **Hans y Olaya**.

## Contenido

- Desarrollo del taller de ciclos anidados.
- Soluciones de los ejercicios propuestos.
- Ejercicios adicionales incorporados posteriormente.
